Sine–cosecant solution · no tangent-function route

Why the area of the circle is exactly π

Keep only one small right triangle. Use sine = opposite ÷ hypotenuse, turn that into cosecant, and then use one deliberately chosen algebraic cancellation.

Radius: r=1  therefore  area: A=π
Read the side label carefully: it is 2 5−25 , with the outer square root covering the whole expression 5−25.

Original image and the single triangle we need

Let O be the centre of the circle, M the point where the circle touches the bottom side, and V the bottom-left vertex.

In a regular pentagon, the centre-to-side line meets the side at its midpoint and at 90°. Therefore triangle OVM is right-angled at M.

∠VOM=36°, OM=r

Write R = OV for the centre-to-vertex distance. It is merely an temporary helper length.

The complete pentagon is mostly a distraction. Everything is contained in the one right triangle OVM.

1

Halve the bottom side

The full side length is

s= 2 5−25

M is the midpoint of the side, so the half-side VM is

VM =s2 = 5−25

For brevity, call this half-side a:

a = 5−25 a2 = 5−25
2

Use sine to obtain the helper hypotenuse R

In right triangle OVM, relative to the 36° angle at O:

Opposite side:
VM = a
Hypotenuse:
OV = R

Therefore, using exactly the route requested,

sin36° = opposite hypotenuse = aR

Rearrange for R:

R = asin36° R = a csc36°

Cosecant is simply the reciprocal of sine: cscθ = 1sinθ.

3

Use Pythagoras to get r² directly

The three sides of the right triangle satisfy

R2 = r2 + a2

So

r2 = R2 − a2

Replace R by a csc36° :

r2 = a2 csc36° 2 − a2 r2 = a2 ( csc36° 2 −1 )

This is the useful “sneaky” form because the question asks for the area πr2. We never actually need to calculate r first.

4

Insert the exact value of sin²36°

The standard exact pentagon-angle value is

sin36° 2 = 5−5 8

Taking the reciprocal gives

csc36° 2 = 8 5−5

Also, from the side length,

a2 = 5−25

Therefore

r2 = (5−25) ( 8 5−5 −1 )
Optional: derive sin²36° instead of memorising it

Let c=cos36°.

Because 3×36°=108° and 108°=180°−72°,

cos108° = −cos72° 4c3−3c = −(2c2−1) (c+1) (4c2−2c−1) =0

Since c is positive, c= 1+54 . Hence

sin36° 2 =1− cos36° 2 = 5−5 8
5

The sneaky cancellation

First combine the fraction inside the brackets:

8 5−5 −1 = 8−(5−5) 5−5 = 3+5 5−5

So

r2 = (5−25) (3+5) 5−5

Now expand only the numerator product:

(5−25) (3+5) = 15+55−65−10 =5−5

That is exactly the denominator, so it cancels:

r2 = 5−5 5−5 =1

A radius is positive, so r=1.

The whole solution in one line

r2 = (5−25) ( 85−5 −1 ) = (5−25) (3+5) 5−5 =1.

The only geometry before this line is sin36° =aR and r2 =R2 −a2.

Final answer

Because the circle has radius 1,

Area =πr2 =π×1 =π

Therefore the exact area of the circle is π square units.
